Privacy Policy

Last updated: 2026-11-06

  • "rclone personal" is used only by its owner, to connect the owner's own rclone software to the owner's own Google Drive.
  • It accesses only the owner's Google Drive files, and only on the owner's own computer.
  • Access credentials are stored only on that computer, in an encrypted rclone configuration file.
  • No Google user data is collected by, sent to, or stored on any server run by the owner, and none is sold or shared with third parties.
  • No other users are asked to sign in. Access can be removed at any time at Google Account → Third-party connections.
  • The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Contact: github.com/msy2004-dotcom

プライバシーポリシー（日本語）

  • このアプリは所有者本人だけが使い、所有者の rclone を所有者自身の Google Drive に接続するためのものです。
  • アクセスするのは所有者の Google Drive のファイルだけで、所有者のパソコンの上でだけ動きます。
  • 認証情報は、そのパソコンの暗号化された rclone の設定ファイルにだけ保存します。
  • Google のユーザーデータを、所有者のサーバーで集めたり、送ったり、保存したりすることはありません。第三者への販売や共有もしません。
  • ほかの人にログインを求めることはありません。アクセスは、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。
